Resource planning

SafeAI provides preliminary estimates for security personnel, police units, medical teams and ambulances based on the predicted risk class and expected crowd size.

These quantities are illustrative only. Actual deployment must follow approved plans, local rules and expert judgement. The application does not dispatch resources.

About SafeAI

Team: Aegis
Project: SafeAI — Intelligent Public Safety Risk Prediction and Resource Allocation System using Machine Learning.

Stack: Python, Flask, scikit-learn, SQLite, HTML, CSS and JavaScript.

Training dataset is synthetic, generated for this academic prototype. Accuracy reflects a held-out split of synthetic labels, not real-world safety performance. Do not use for operational emergency decisions. Real-world use requires validated data and expert assessment.

Architecture

Browser UI → Flask REST API
Flask → scikit-learn model
Model results → SQLite history
CSV → training + evaluation
